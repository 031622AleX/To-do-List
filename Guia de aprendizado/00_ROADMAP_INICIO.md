    print(i)

# Teste também:

## 🐛 DEBUGGING (Encontrando Erros)

### Técnica 1: Print Debugging
```python
# Quando algo está errado:
print("Valor de x:", x)
print("Tipo de x:", type(x))
print("Tamanho da lista:", len(tarefas))

# Descubra o problema antes de consertar
```

### Técnica 2: Rastreamento
```python
# Adicione prints em pontos-chave
def adicionar_tarefa(tarefas):
    print("1. Entrando em adicionar_tarefa")
    nome = input("Nome: ")
    print("2. Nome digitado:", nome)
    
    tarefas.append(nome)
    print("3. Adicionada à lista")
    print("4. Tamanho da lista:", len(tarefas))
```

### Técnica 3: Validação
```python
# Sempre valide dados
nome = input("Digite algo: ")

if not isinstance(nome, str):
    print("❌ Deveria ser string!")

if not nome or nome.isspace():
    print("❌ Está vazio!")

# Só continua se válido
```
