## 🚀 COMO USAR EFETIVAMENTE

### Para Cada Fase:

```
1. LER (5-10 min)
   ├─ Entenda o objetivo
   ├─ Leia os conceitos
   └─ Veja os exemplos

2. ESCREVER (20-30 min)
   ├─ Crie arquivo (aula_01.py, aula_02.py, etc)
   ├─ Digite TODO o código
   ├─ NÃO copie/cole
   └─ Faça o exercício

3. TESTAR (10-15 min)
   ├─ Execute o programa
   ├─ Teste valores diferentes
   ├─ Tente quebrar
   └─ Conserte erros

4. COMPARAR (5 min)
   ├─ Veja a solução
   ├─ Você fez igual?
   ├─ Que diferenças tem?
   └─ Por que fez diferente?

5. REVISÃO (5 min)
   ├─ Responda o checkpoint
   ├─ Todas as respostas = SIM?
   └─ Pode ir para próxima fase!
```

**Tempo por fase: 45-70 minutos**
